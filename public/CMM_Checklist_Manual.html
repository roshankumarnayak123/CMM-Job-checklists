CMM Checklist - User Manual

Comprehensive Operations and Administration Guide (v2.0)

Welcome to the official Central Mechanical Maintenance (CMM) Checklist application manual. This modernized platform digitizes, tracks, and standardizes maintenance protocols, ensuring seamless compliance and cross-departmental reporting.

🎯 1. Overview of the System

The CMM Checklist application is built with a state-of-the-art "Glassmorphism" interface and operates across three primary user journeys:

  • Junior Engineer (CMM) Flow: Execution of maintenance checklists, data entry, image capture, and primary digital signature.
  • Junior Engineer (AMM) Review Flow: Independent verification process via secure sharing links to review, add notes, and counter-sign submitted tasks.
  • Admin Dashboard: Centralized management of checklist templates, user activity logs, data retention, and PDF report generation.

🛠️ 2. Junior Engineer Operations (CMM)

Selecting and Filling Checklists

  • Task Selection: Use the left-hand sidebar to select the specific equipment or area checklist assigned to you.
  • Data Entry: Follow the on-screen prompts for each checkpoint. You may be asked to toggle Yes/No, select options, or provide specific numerical readings.
  • Mandatory Photos: If a checkpoint requires visual evidence, click "Attach Photo" to upload an image of the machinery.

CMM Signature and Submission

  • Automated Dates: The signature date is auto-captured directly from the system clock to ensure data integrity.
  • Designation: Provide your name and exact designation (e.g., Senior Mechanical Engineer).
  • Tracking Code: Upon clicking "Submit Checklist", the system will generate a unique 10-character Tracking Code. Save this code! You can use it to share the checklist with the AMM or fill another checklist immediately.

✅ 3. Area Maintenance (AMM) Review Process

Once the Junior Engineer (CMM) submits a checklist, it must be verified by the Junior Engineer (Area Maintenance).

  • Accessing the Report: The AMM can access the report by navigating to the unique review link (e.g., /review/TRACKING_CODE) provided by the Junior Engineer (CMM).
  • Reviewing Data: The AMM can view all recorded checkpoint answers, uploaded photos, and CMM notes. This data is strictly read-only to prevent tampering.
  • Counter-Signature: After verification, the AMM can add their own remarks and electronically sign off on the job. The AMM signature date is also auto-captured.

👑 4. Administrator Dashboard & Features

Submission Tracking & PDF Reports

  • Live Dashboard: Admins can view all submitted checklists in real-time. Submissions indicate whether they are pending AMM review or fully completed.
  • PDF Generation: Click on any submission to view its details, then click "Print / Save PDF". The system will automatically generate a highly-formatted, offline-ready PDF report featuring the official Tata Steel branding.

System Settings & Auditing

  • Audit Logs: The system automatically tracks critical events (e.g., template creation, data deletion). The audit log stores the most recent 200 operations to maintain performance while ensuring accountability.
  • Master Data Deletion: In the System settings, admins can execute a complete cloud data wipe (clearing all submissions, templates, and review links). This requires a secure master password to prevent accidental data loss.
Security Note: Your application data is synced securely with the Cloud Server. Ensure you have a stable internet connection when submitting checklists with high-resolution images. If the app goes offline, wait for the connection to re-establish before clicking Submit.
